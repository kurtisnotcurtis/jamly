Four ways to run Jamly

Use the standalone desktop companion, command-line tools, browser extension, or lightweight userscript—all backed by the same durable local queue.

Zero-Setup Desktop Companion

Portable archives for macOS (Apple Silicon & Intel), Windows x64, and Linux x64 bundle Python, Demucs, yt-dlp, Deno, ffmpeg, and ffprobe out of the box.

  1. Launch the app: Open Jamly.app (macOS), Jamly.exe (Windows), or Jamly (Linux).
  2. Automatic private pairing: Jamly opens your browser via a single-use launch file and establishes an authenticated loopback session without putting tokens in URLs.
  3. Submit URLs or local files: Paste individual track URLs, enter local paths, or pick audio files (.wav, .mp3, .flac, .m4a, .ogg, .opus) directly from your computer.
  4. Close the tab anytime: Separation continues in the background worker and resumes automatically on restart.
Output directory layout 
~/Music/jamly/
  Artist - Song [id]_drums.mp3
  Artist - Song [id]_no_drums.mp3

All exported stems land directly in a single flat folder for easy browsing, while internal manifests stay tucked in .jamly/.

Command-Line Interface & Login Service

Install from source with uv and system ffmpeg. Run one-off batch jobs in the terminal, launch the companion web UI, or register a per-user background service.

  1. Install & verify: Run jamly-doctor to check Python, yt-dlp, Deno, ffmpeg, and Torch device detection (CUDA / MPS / CPU).
  2. Split URLs or local files: Pass -i flags or pipe newline-separated URLs and local file paths to jamly.
  3. Optional login service: Use jamly-service install to create a user systemd unit (Linux), LaunchAgent (macOS), or logon Scheduled Task (Windows).
Terminal commands 
# Install with uv (Python 3.11 or 3.12)
uv tool install --python 3.12 git+https://github.com/kurtisnotcurtis/jamly.git
jamly-doctor

# Split a URL or local audio file (drums, karaoke vocals, guitar, or all stems)
jamly -i "https://youtu.be/VIDEO_ID"
jamly -i "https://youtu.be/VIDEO_ID" --stem vocals
jamly -i "~/Music/my_song.flac" --model htdemucs_6s --stem guitar --audio-format wav
jamly -i "https://youtu.be/VIDEO_ID" --model htdemucs_ft --replace-existing

# Launch the local companion UI or background service
jamly-companion
jamly-service install --audio-format wav --port 8765

Chrome & Edge Browser Extension

Send the active browser tab directly to your local Jamly backend, monitor live separation percentages, retry failed jobs, and trigger authenticated downloads from the toolbar popup.

  1. Export the unpacked extension: In the Companion UI, expand Optional Chrome / Edge extension and click Prepare extension (or run jamly-service browser in the CLI).
  2. Load unpacked: Open chrome://extensions or edge://extensions, enable Developer mode, click Load unpacked, and select the exported folder.
  3. Pair with your token: Open the extension's Pair / settings page and paste the backend URL (http://127.0.0.1:8765) and private token from the companion or jamly-service token.
  4. Split with one click: Click Use current page, choose your preset, and press Split drums.
Export & pair via CLI 
# Start the local backend (if not using jamly-companion)
jamly-server

# Print the unpacked extension directory and pairing token
jamly-service browser
jamly-service token

The extension requests active-tab access only when clicked and polls only while its popup is open.

Tampermonkey / Violentmonkey Userscript

Prefer not to load an unpacked extension? Jamly includes a lightweight userscript for YouTube and YouTube Music that adds an on-page status badge and one-click enqueue button.

  1. Export the script: Run jamly-service userscript to copy jamly.user.js to your user state directory.
  2. Install in your userscript manager: Drag or import jamly.user.js into Tampermonkey or Violentmonkey.
  3. Pair with your token: On YouTube or YouTube Music, open the userscript menu command Pair Jamly and paste the token from jamly-service token.
  4. Enqueue while browsing: Click the Jamly button on any video page to queue it on your local backend.
Export userscript 
# Export jamly.user.js and retrieve your pairing token
jamly-service userscript
jamly-service token

Connects exclusively to http://127.0.0.1:8765 using GM_xmlhttpRequest with your Bearer token.

Separation presets & audio integrity

Every preset outputs a sample-aligned drums and no_drums pair with a single shared gain so stem balance is never distorted.

Default · 1x Speed

Balanced (htdemucs)

Official 4-stem Hybrid Transformer Demucs model. Fast single-model inference suitable for everyday practice tracks.

Fine-Tuned · ~4x Slower

Higher quality (htdemucs_ft)

Evaluates a four-model fine-tuned bag (dedicated per-stem transformers). Can reduce cymbal bleed on dense mixes at ~4x compute cost.

6-Source · 1x Speed

6-stem (htdemucs_6s)

Separates drums, bass, guitar, piano, vocals, and other in a single pass, then sums all five non-drum stems in 64-bit float blocks for the drumless mix.

Unscaled Float32 Stems

Bypasses Demucs' default per-stem rescaling/clamping so summing drums + no_drums reconstructs the relative mix balance.

4x-Oversampled MP3 Peak Check

320 kbps MP3 exports are decoded and checked with a 4x-oversampled true-peak filter targeting -1 dBFS to prevent lossy inter-sample clipping.

Transactional Exports

Outputs and SHA-256 manifests are staged, fsynced, and swapped atomically with automatic rollback if interrupted.

Built for local security & durability

Localhost tools shouldn't expose your filesystem or leak credentials to random tabs.

HMAC Identity Handshake

Before sending a pairing token, the launcher challenges the backend with a 256-bit nonce bound to the loopback URL and queue path.

Zero Tokens in URLs

Companion sessions bootstrap via a private 0600 single-use HTML form post into tab-scoped sessionStorage—never query parameters.

Host & Origin Isolation

Every request validates HTTP Host and browser Origin headers independently of authentication to block DNS rebinding and cross-site probing.
